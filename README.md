# ПензГТУ · новый интерфейс

Это расширение для Chrome/Edge. Оно накладывает новый интерфейс на настоящий портал `edu.penzgtu.ru`, но не заменяет его и не меняет сервер.

## Установка

1. Распакуйте архив `penzgtu-real-skin.zip` в отдельную папку (внутри должен лежать `manifest.json`).
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
5. Откройте `https://edu.penzgtu.ru/login/index.php` и войдите своим обычным логином.

Если Chrome при запуске спрашивает про расширения в режиме разработчика — оставьте расширение включённым.

## Что меняется

- Экран входа: тёмная редакционная панель и аккуратная форма.
- Шапка: «Главная», «Мои курсы», «Календарь», «Сообщения», «Личные файлы», профиль и выход.
- На «Главной»: сначала «Недавно посещённые курсы», затем «Шкала времени» и в конце «Календарь».
- В своём профиле убрана нерабочая кнопка «Сообщение». Ссылка «Сообщения» в шапке остаётся.
- Каталог, карточки курсов, задания, файлы и оценки: спокойная бумажная тема, крупная типографика, квадратные кнопки.
- Мобильная вёрстка без горизонтальной прокрутки; на узких экранах вкладки сокращаются до «Курсы» и «Файлы».
- На телефоне крупнее элементы навигации, кнопки «Сохранить» и «Отмена» занимают всю ширину, а файловый менеджер получает крупные кнопки.
- В заданиях и «Личных файлах» появилась панель «Несколько файлов сразу»: можно выбрать сразу несколько файлов, и все они загрузятся в один заход, без повторов «выбрать → загрузить».

## Телефон

Вёрстка адаптирована под экраны 360–430 px. Важно: Chrome для Android не поддерживает расширения. Чтобы открыть портал с этим слоем на телефоне, нужен браузер с поддержкой расширений Chromium, например **Kiwi Browser**: установите его, откройте меню расширений, включите режим разработчика и загрузите распакованную папку из архива. В обычном мобильном Chrome портал откроется в стандартном виде Moodle.

Все курсы, файлы, задания и оценки — настоящие: расширение только перерисовывает страницы, которые отдаёт Moodle. Новые курсы появятся сами, потому что это тот же портал.

## Чего расширение не делает

- Не читает и не сохраняет пароль. Пароль вводится в настоящую форму Moodle.
- Не меняет `edu.penzgtu.ru` для других людей. Это персональный слой в вашем браузере.
- Не работает, если открыть портал в другом браузере или на другом компьютере без установки расширения.

## Удаление

`chrome://extensions` → выключить или удалить «ПензГТУ · Новый интерфейс».
